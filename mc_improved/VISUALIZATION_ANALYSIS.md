# 三张核心可视化的解读与分析（mc_improved）

本文档针对 **冰山图**、**漏斗图**、**山峦图** 三张 MCM 亮点图做完整解读，说明每张图的设计目的、如何读图、以及如何支撑赛题两问与模型特性。

---

## 1. 冰山图（The Reconstruction）：重构得分机制

**文件**：`figures/fig8_iceberg_reconstruction.png`  
**类型**：堆叠柱状图 + 误差棒（Stacked Bar with Error Bars）

### 1.1 设计目的

- 直观展示 **Total = Judge + Fan** 的构成：综合得分由“已知的裁判份额”与“估计的观众投票份额”两部分叠加。
- 将**已知量**（裁判分）设为深色实心，**估计量**（观众分）设为浅色并加上 **±1σ 误差棒**，体现模型是对**分布**的估计，而非单一猜测。
- 用一条**横虚线**表示“淘汰阈值”（Rule A 下为幸存者中的最低总分），说明为何某人被淘汰（总分低于该线）。

### 1.2 如何读图

- **横轴**：当周选手（按**总分由低到高**排序，便于看到“谁在最下面”）。
- **纵轴**：综合得分（裁判份额 + 观众份额），范围约 0–1（当周归一化后）。
- **每根柱子**：
  - **下半段（深色）**：裁判份额 \(j_i\)（已知）。
  - **上半段（浅色）**：观众份额后验均值 \(\hat{v}_i\)（估计）。
  - **顶端误差棒**：观众份额的 **±1 标准差**（\(\hat{\sigma}_i\)），即总分的上下界约为 \(j_i + \hat{v}_i \pm \hat{\sigma}_i\)。
- **红色虚线**：淘汰阈值 = \(\min\{T_k : k \in \text{幸存者}\}\)。总分**低于**该线的选手在该规则下应被淘汰（本例为 Rule A，即总分最低者出局）。

### 1.3 解读与结论

- **构成透明**：一眼可见每位选手的总分中，裁判贡献多少、观众贡献多少；裁判分低者若未被淘汰，则必然在“观众分”上有一定下界（否则总分会更低），与约束逻辑一致。
- **不确定性可见**：误差棒表明我们给出的是**后验分布**的均值与标准差，而非一个点估计；评委分高、晋级的选手，观众分的后验往往更分散（误差棒更长）。
- **淘汰逻辑可验证**：被淘汰者（通常为最左侧、总分最低的柱子）的总分落在红线下方或附近，与“淘汰阈值”的设定一致，可用于在论文中说明模型与淘汰规则的自洽性。

**MCM 亮点**：将已知/估计分离、误差棒体现分布估计、淘汰阈值线体现规则，三者结合能有力支撑“重构得分机制”的叙事。

## 2. 漏斗图（The Constraint Funnel）：揭示不确定性的物理规律

**文件**：`figures/fig9_funnel_judge_vs_certainty.png`  
**类型**：散点图（Scatter Plot）

### 2.1 设计目的

- 直接回答赛题第二问中的 **“确定性是否因人而异”**。
- **X 轴**：裁判分份额（已知）；**Y 轴**：估计的确定性（Certainty = 1 − 后验极差）。
- 用不同颜色区分**当周被淘汰者**与**晋级者**，观察二者在“裁判分–确定性”平面上的分布差异。

### 2.2 如何读图

- **横轴**：Judge share（当周裁判份额，0–1）。
- **纵轴**：Certainty（0–1），越大表示该选手当周观众投票的后验越集中、估计越“确定”。
- **蓝色点**：当周晋级者；**橙/红色点**：当周被淘汰者（可带边框突出）。

### 2.3 解读与结论：漏斗形态

- **典型形态**：裁判分**低**的选手，确定性往往**高**（点偏上）；裁判分**高**的选手，确定性往往**低**（点偏下）。整体呈“漏斗”或负相关形态。
- **物理原因**：
  - 裁判分低且**晋级**的选手：观众分必须“足够高”才能把总分拉上去，约束强，后验被压在一个相对窄的区间 → Certainty 高。
  - 裁判分低且**被淘汰**的选手：观众分被约束在“足够低以使总分最低”，同样约束强 → Certainty 高。
  - 裁判分**高**且晋级的选手：观众分只需“不低于某下界”即可，可行域大 → 后验分散，Certainty 低。
- **淘汰者 vs 晋级者**：淘汰者在图中多集中在裁判分中低、确定性中高的区域；晋级者则遍布裁判分从低到高，且高裁判分区域以晋级者为主、Certainty 偏低。这与“约束不对称”一致：**低分端约束紧、高分端约束松**。

**MCM 亮点**：该图用数据直接展示“裁判分–确定性”的负相关与淘汰/晋级分色，证明模型捕捉到了**约束的不对称性**，是回答“确定性是否因人而异”的加分项。

## 3. 山峦图（Ridge Plot）：展示后验分布全貌

**文件**：`figures/fig10_ridge_posterior.png`  
**类型**：山峦图 / 脊线图（Ridge Plot）

### 3.1 设计目的

- 对**某一特定周**（如 S3 Week 5）所有选手的观众投票份额，展示**完整后验分布**（近似 PDF），而非仅均值或均值±1σ。
- 对比“分布尖”的选手（估计确定）与“分布扁”的选手（估计不确定），体现数学上的后验形状差异。

### 3.2 如何读图

- **横轴**：Fan vote share（观众投票份额，0–1）。
- **纵轴**：每位选手占一行（脊线），从上到下排列；**曲线高度**表示该选手在该投票份额处的**后验密度**（由 MH 样本做 KDE 得到）。
- **峰尖**：分布集中，后验标准差小，Certainty 高。  
- **峰扁 / 多峰**：分布分散，后验标准差大，Certainty 低。

### 3.3 解读与结论

- **形态差异**：同一周内，有的选手脊线**尖而窄**（观众分被约束在很小区间），有的**扁而宽**（观众分可行域大）。这与冰山图中“误差棒长短”一致，也与漏斗图中“高/低确定性”对应。
- **淘汰与晋级**：通常被淘汰者（总分最低）的脊线更集中在低观众分一侧且较尖；高观众分、晋级的选手脊线可能更扁或拖尾更长。
- **数学味**：相比只画均值±1σ，山峦图展示的是**整条后验密度曲线**，更符合“贝叶斯推断给出的是分布”的表述，适合在论文中突出方法的严谨性。

**MCM 亮点**：用后验 PDF 形态（尖 vs 扁）直观回答“估计的确定性如何、是否因人而异”，并可与 Certainty 指标、漏斗图相互印证。

## 4. 三张图与赛题两问的对应

| 赛题要求 | 冰山图 | 漏斗图 | 山峦图 |
|----------|--------|--------|--------|
| **估计的投票是否与淘汰结果一致？** | 展示 Total=Judge+Fan 与淘汰阈值线，可验证“被淘汰者总分低于阈值” | — | — |
| **一致性度量** | 与一致性 C 互补：图展示“单周、单规则”的构造 | — | — |
| **估计的确定性如何？** | 误差棒体现后验不确定性 | Y 轴即 Certainty，直接度量 | 脊线尖/扁即确定性高/低 |
| **确定性是否因人/周而异？** | 不同柱子误差棒长短不同 | **核心图**：裁判分–确定性负相关、淘汰/晋级分色 | 不同选手脊线形态不同 |
